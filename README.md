## 📌 Visão Geral

Este repositório documenta a minha jornada de resolução de problemas algorítmicos no **[LeetCode](https://leetcode.com/)**. O foco principal é dominar a resolução de problemas em **Modern C++ (C++17/C++20)**, explorando a **Standard Template Library (STL)**, técnicas clássicas de algoritmos e otimização rigorosa de complexidade de tempo e memória.

### Objetivos Principais
- 🎯 Construir uma base sólida começando pelos problemas **Easy** e evoluindo para **Medium** e **Hard**.
- ⚡ Dominar o uso eficiente da STL (`std::vector`, `std::unordered_map`, `std::priority_queue`, `std::set`, etc.).
- 🧠 Implementar padrões algorítmicos reconhecidos (Two Pointers, Sliding Window, DP, DFS/BFS, Backtracking, etc.).
- ⏱️ Analisar e documentar formalmente a complexidade assintótica ($\mathcal{O}(N)$) de cada solução.
